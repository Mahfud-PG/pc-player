## Versi 2.0.0 (Python Asli)
- **Rombak Total**: Beralih dari teknologi web (Electron) ke aplikasi Windows murni menggunakan Python dan PyQt6.
- **Perbaikan Masalah**: Mengatasi masalah *drag and drop* yang gagal karena kendala URL pada sistem lama.
- **Klik Kanan Cerdas**: Menambahkan menu *context* (Klik Kanan) pada aplikasi untuk:
  1. Mengganti tema (Gelap / Terang).
  2. Beralih ke layar penuh (khusus video).
  3. Mendaftarkan aplikasi ke Windows sebagai pemutar utama (Open With).
- **Desain Baru**: Antarmuka QSS bergaya elegan layaknya aplikasi profesional.
- **Multimedia Utuh**: Dukungan putar video (.mp4, .webm) dengan layar terpisah yang otomatis muncul, dan tentu saja semua format audio (.mp3, .wav, .flac, .opus, dll).

## Versi 1.0.0 (Ditinggalkan)
- *Eksperimen awal menggunakan Electron, ditinggalkan karena kurangnya integrasi dengan sistem operasi Windows.*
